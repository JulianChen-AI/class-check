class-check · 课程检查

仅限非商业使用

给 Codex、WorkBuddy 一套从微信记录到资料清单的处理流程：需要时先准备 WCE，再导出、阅读和核对，最后给你一份有依据的梳理。

这是一个 Agent Skill，不是独立聊天软件，也不是网页上传分析工具。你的聊天、密钥和课程文件不需要上传到这个展示页。

安装与使用 下载源码 阅读完整 Skill

可以做什么

  • 梳理重要事项：作业截止、考试范围、展示排期、签到要求；比赛项目则整理赛程、交付物、分工和会议决策。
  • 读记录，也读附件：不把一张截图当成全部群历史，重要结论保留通知日期和附件依据。
  • 按内容找缺漏：附件改了名字仍能识别；同名但内容不同，会提示版本差异。
  • 给出能用的报告：重要事项在前，基本信息用表格，缺少的资料带实际可用链接。

哪些文件没有放进目标文件夹？

列出缺少文件的名称、用途、群发送日期与可用附件链接；行政统计表、名单和视频单独说明。

报告中的数量、日期与文件都来自本次实际读取，不套用示例数字。比赛项目会换成对应字段，不硬套课程作业。

安装与使用

宿主需要支持读取本地文件、执行 Python 工具。将仓库放入对应的 Skill 目录；目标目录已存在时，先检查和备份，不要直接覆盖。

让宿主重新读取 Skill，提供群名／截图和资料目录，然后说：

用 class-check 梳理这门课或比赛项目。需要时先引导安装和配置 WCE，导出真实群记录，再整理重要事项、基本信息，并核对本地资料缺漏。

安装命令和提示词均可直接选中复制。

Skill 的 Python 辅助脚本需要 Python 3.9+。WCE 的新机源码安装另需 Apple Silicon、macOS 13+ 和原生 Python 3.11，具体以其官方安装说明为准。已有可用环境或档案时优先复用。

技术结构

Codex / WorkBuddy
    └─ class-check Skill：组织流程、阅读证据、生成报告
        ├─ WCE（外部）：安装、配置、导出真实群记录
        ├─ prepare-check.py：检查已有来源与下一步
        ├─ compare-attachments.py：附件身份与内容核对
        └─ ocr-image.swift：必要时在本地识别截图文字

消息中的 MD5 与字节数用于确认附件身份，SHA-256 用于比较本地文件内容。WCE 不内嵌到 Skill 中；准备、安装和导出按授权在外部完成。

当前状态与边界

已实现 WCE 准备、首次配置、导出和分析的流程指引，以及来源预检、附件核对和可选的 macOS 本地 OCR。预检和文件核对已有离线行为回归。

  • 本机可导出的记录，不保证覆盖手机全部历史；缺失媒体和不可读附件会单独说明。
  • 默认只读分析，不自动补拷、覆盖课件，不发消息、邮件或提醒。
  • 截图通常是识别线索，不是群历史；只有你明确要求时才只分析截图。
  • Skill 不能控制宿主模型。干净 Mac 首次安装及不同宿主的实际执行效果，仍需实机验证。
